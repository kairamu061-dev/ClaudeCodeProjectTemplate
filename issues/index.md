# バグチケット一覧

## ステート凡例

| ステート | 説明 |
|---------|------|
| Open | 未着手 |
| In Progress | 対応中 |
| Awaiting Decision | 修正するかどうかユーザーの判断待ち（票に修正の影響を記載済み） |
| Fixed | 修正済み（未検証） |
| Closed | 修正確認済み |
| Won't Fix | 修正しないと判断（理由は票に記載） |

## ランク（症状で決める）

| ランク | 説明 |
|------|------|
| S | 進行不能・クラッシュ・データ破損など重篤な不具合 |
| A | エラーで巻き戻される・効果が発揮されない・ボタンが動作しないなど、動作に支障が出る不具合 |
| B | 異なる効果が呼び出される・テクスチャの参照が切れて白いポリゴンが出る・画面が崩れる・値が違うなど、一目で問題と分かる不具合 |
| C | 想定より遷移に時間がかかる・画面が一瞬ちらつく・文字がはみ出すなど、軽微な問題 |

## タイプ（原因で決める）

| タイプ | 説明 |
|------|------|
| 通常 | 通るはずの処理を通らない・true/false の判定が逆など、ロジックの記述ミス |
| 例外 | 仕様で想定していない挙動で、通常の仕組みでは吸収できず例外処理が必要なもの |
| 競合 | それぞれは仕様どおりだが、組み合わせやタイミングによってバグとして表面化したもの |
| 仕様 | 実装は仕様どおりだが、仕様そのものが誤っている・曖昧なもの |
| 外部 | ライブラリ・OS・外部 API 側の不具合で、こちらでは回避策で対処するもの |
| その他 | 上のいずれにも当てはまらないもの |

**即時修正**: ランクが S か A、またはタイプが「通常」のもの。それ以外は修正の影響を挙げたうえでユーザーが判断する。
