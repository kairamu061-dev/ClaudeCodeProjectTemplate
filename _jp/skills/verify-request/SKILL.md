次のコマンドを実行してください。

```bash
bash "${CLAUDE_SKILL_DIR}/verify-request.sh" $ARGUMENTS
```

その後、生成されたファイルを開いて埋めてください。**成果物の表は編集しないこと** — 成果物から
測ったものです。**報告の書式も編集しないこと** — その「未了・判定できなかった項目」の見出しを、
次回の実行が読み取って項目を引き継ぎます。それ以外の節はすべてあなたが書きます。

完了と報告する前に、次の4つをすべて確認してください。

1. **測ったこと / 推測していること** が埋まっている。印の無い主張は不可。
2. すべての項目に **対照** がある。存在しない場合は「無し（確認のみ）」と書き、
   「対照が無い項目」の節で、その理由と、それでも何が結論できるかを説明している。
3. 期待値が `0` の項目はすべて **`0` を期待値に置いた項目** の表に載っており、
   `1` になるケースか、数えている文字列が出荷されたバイナリに存在する証拠のどちらかが添えてある。
4. 事実は以前の文書から写したのではなく、**今取り直した**もの — パスやレジストリキーは
   製品から読み取り、数値は成果物から取っている。

生成されたファイルのパスと、スクリプトが測れなかったものを報告してください。
