# 移植・書き直しのための回帰の網

UI フレームワーク・ランタイムなど、層を丸ごと置き換えるときに読む。

**旧 `spec.md` の機能一覧のすべての項目**を、済 / 要 / 差（完了 / 要確認 / 意図的に異なる）に
対応づける網羅表を作る。

- **表の起点は、旧テストケースではなく spec の機能一覧にする。**
  テストケースの無い機能は、テストケースから作った表には現れず、黙って落とされる。
  実際に起きたことがある：「非同期読み込み」という spec の項目が移植で失われ、
  数週間後にユーザが遅さを報告するまで気づかれなかった
- 表は**旧実装がまだ動くうちに**作る。旧実装を消してしまうと、比較は二度と取れない
- 段階的な確認は、各段階で追加したものしか確かめないので、移植で忘れたものは捉えられない。
  それを捉えられるのはこの表だけである
