# プロジェクトルール

このプロジェクトの開発プロセスとドキュメント規約は `rules/` 配下で定めています。
実装タスクを受けたら、それに従い、作業を始める前にドキュメントを用意してください。

## 常に読む

@rules/principles.md
@rules/workflow.md
@rules/structure.md

## 必要なときに読む

その作業を始める**前に**、該当するファイルを読んでください。

| いつ | 読むもの |
|---|---|
| バグが報告されたとき、またはバグ票を作成・更新しようとするとき | `rules/bugs.md` |
| プロジェクトを始めるとき、または何を自動テストにするか決めるとき | `rules/automated-tests.md` |
| 自分で製品を動かせず、実機での確認が必要なとき | `rules/verification.md` |
| UI フレームワーク・ランタイムなど、層を丸ごと置き換えるとき | `rules/porting.md` |

## 禁止事項

- `_jp/` 配下のファイルを読み込んだり参照したりしないこと。このディレクトリは人間が参照するためだけのもの
